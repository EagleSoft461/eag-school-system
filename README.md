# 🎓 Öğrenci Bilgi Sistemi

Java ile geliştirilmiş tam teşekküllü öğrenci yönetim sistemi.

## ✨ Özellikler

- 👨‍🎓 **Öğrenci Yönetimi** - Ekleme, silme, güncelleme
- 👨‍🏫 **Öğretmen Yönetimi** - Öğretmen kayıtları ve ders atama
- 📊 **Not Sistemi** - Vize, final, transkript
- 📅 **Devamsızlık Takibi** - Mazeret yönetimi
- 🗃️ **MySQL Veritabanı** - Güvenli veri saklama
- 🎨 **GUI Arayüz** - Kullanıcı dostu arayüz

## 🛠️ Teknolojiler

- Java
- MySQL
- Swing (GUI)
- JDBC

## 📦 Kurulum

1. MySQL veritabanını kurun
2. `DatabaseConnection.java` dosyasında bağlantı bilgilerini güncelleyin
3. Projeyi çalıştırın

## 🚀 Kullanım

Sistem otomatik olarak gerekli tabloları oluşturacak ve örnek verileri ekleyecektir.
